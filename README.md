# فرصت‌های شغلی فلووین

داشبورد فارسی فلووین فرصت‌های پرفورمنس مارکتینگ، سئو و شبکه‌های اجتماعی را در جاب‌ویژن و جابینجا برای همهٔ شهرها نشان می‌دهد. مدیر می‌تواند گزارش روز را انتخاب کند، عنوان، شرکت یا شهر را جست‌وجو کند و برای ارسال دستی رزومه، آگهی اصلی را باز کند.

برای انتخاب چند آگهی و بررسی حساب‌ها، افزونهٔ مرورگر را طبق [راهنمای افزونه](extension/README.md) نصب کنید. افزونه با حساب‌های واردشده در همان مرورگر کار می‌کند و وضعیت ورود را پس از بررسی در داشبورد نشان می‌دهد.

## مشاهدهٔ داشبورد روی سیستم

در پوشهٔ پروژه دستور زیر را اجرا کنید و [داشبورد محلی](http://127.0.0.1:8000/) را باز کنید. پیش‌نمایش از پایگاه دادهٔ کراولر روی همین دستگاه می‌خواند. در یک کپی تازه از پروژه، گزارش واقعی ۶۰۰ آگهیِ ۲۱ نوامبر ۲۰۲۶ همراه برنامه است.

```powershell
$env:CRON_SECRET = "یک-کلید-دلخواه"
python -m jobscrawler.serve
```

برای اجرای دستی، همان کلید را در بخش «دریافت آگهی‌های تازه» داشبورد وارد کنید. در Vercel مقدار این کلید همان `CRON_SECRET` محیط Production است. اجرای دریافت ممکن است چند دقیقه طول بکشد. دکمهٔ CSV همهٔ نتایج فیلترشدهٔ گزارش انتخابی را دانلود می‌کند.

## انتشار برای تیم روی Vercel

۱. در حساب Vercel خود، یک پروژه برای این پوشه بسازید. می‌توانید مخزن Git را با گزینهٔ **Add New → Project** وارد کنید یا از پوشهٔ پروژه دستورهای زیر را اجرا کنید. در روش CLI، دستور دوم پوشه را به پروژه وصل می‌کند.

```powershell
npx vercel login
npx vercel link
```

۲. برای به‌روزرسانی روزانه، یک پایگاه دادهٔ PostgreSQL مانند Neon را از بخش Storage به پروژه متصل کنید. در **Settings → Environment Variables** این دو مقدار را برای **Production** تنظیم کنید.

| متغیر | مقدار |
| --- | --- |
| `DATABASE_URL` | آدرس اتصال PostgreSQL با اجازهٔ ایجاد schema و جدول. در Neon از آدرس pooled با TLS استفاده کنید. |
| `CRON_SECRET` | یک رشتهٔ تصادفی محرمانه. می‌توانید با `python -c "import secrets; print(secrets.token_urlsafe(32))"` آن را روی دستگاه خود بسازید. |

۳. پروژه را با **Deploy** یا دستور زیر در محیط Production منتشر کنید. اگر متغیرها را بعد از انتشار اول اضافه کردید، یک‌بار **Redeploy** کنید. تنظیمات پروژه در `vercel.json` آماده است. از پوشهٔ ریشهٔ پروژه، preset «Other» و Fluid Compute استفاده کنید. لینک دامنهٔ Production را برای مدیر بفرستید.

```powershell
npx vercel --prod
```

صفحهٔ اصلی برای مرور تیمی فقط‌خواندنی است و با تنظیمات معمول یک دامنهٔ عمومی، هر دارندهٔ لینک می‌تواند آگهی‌ها را ببیند. در اولین استفاده، برنامه schema و سابقهٔ گزارش اولیه را در PostgreSQL ایجاد می‌کند. داشبورد بدون `DATABASE_URL` نیز گزارش همراه برنامه را با برچسب نسخهٔ ذخیره‌شده نشان می‌دهد. دریافت روزانه به هر دو متغیر نیاز دارد.

Vercel Cron مسیر `/api/cron` را هر روز در محیط Production برای ساعت ۰۴:۳۰ UTC (۰۸:۰۰ تهران) زمان‌بندی می‌کند. دقت زمان به پلن Vercel بستگی دارد. برای بررسی اولین اجرا، در بخش Cron Jobs پروژه **Run** را بزنید و نتیجه را در Logs و داشبورد ببینید. وضعیت هر منبع در همان گزارش ثبت می‌شود. [راهنمای Cron در Vercel](https://vercel.com/docs/schedules/cron-jobs/manage-cron-jobs) · [دقت زمان‌بندی](https://vercel.com/docs/schedules/cron-jobs/usage-and-pricing)

## اجرا و گزارش

برای دریافت آگهی‌ها و ساخت گزارش HTML روی دستگاه، از پوشهٔ پروژه با Python 3.11 یا بالاتر اجرا کنید. مسیر محلی با کتابخانهٔ استاندارد پایتون کار می‌کند. Vercel در زمان ساخت، درایور PostgreSQL را از `requirements.txt` نصب می‌کند.

```powershell
python -m jobscrawler
```

گزارش هر روز در `reports/YYYY-MM-DD.html` ذخیره می‌شود. نام فایل بر اساس تاریخ میلادی تهران است. اولین اجرا آگهی‌های مرتبط فعلی را ثبت می‌کند. در روزهای بعد فقط آگهی‌هایی به گزارش آن روز اضافه می‌شوند که برای اولین بار دیده شده‌اند. تاریخ درج آگهی در سایت می‌تواند قدیمی‌تر باشد. اجرای مجدد همان روز گزارش را به‌روز می‌کند. فایل `data/jobs.sqlite3` سابقهٔ شناسایی آگهی‌هاست و باید بین اجراها حفظ شود.

جست‌وجو برای هر عبارت فارسی و انگلیسی، تازه‌ترین صفحات هر سایت را می‌خواند و عنوان آگهی را بررسی می‌کند. سقف پیش‌فرض برای هر عبارت در هر سایت ۵ صفحه است. آگهی با شناسهٔ ثابت در همان سایت یک بار ثبت می‌شود. انتشار یک فرصت در هر دو سایت می‌تواند دو لینک مستقل داشته باشد.

برای نمونه، این دستور فقط جابینجا را تا ۱۰ صفحه برای هر عبارت بررسی می‌کند.

```powershell
python -m jobscrawler --source jobinja --max-pages 10
```

برای جاب‌ویژن از `--source jobvision` استفاده کنید. اگر سایتی پاسخ معتبر ندهد، خطای آن در گزارش ثبت می‌شود و برنامه با کد ۱ خاتمه می‌یابد. آگهی‌های صفحه‌هایی که تا آن لحظه با موفقیت خوانده شده‌اند در گزارش می‌مانند. همان روز می‌توانید جست‌وجوی منبع ناموفق را دوباره اجرا کنید.

در این سیستم، زمان‌بندی قبلی Codex ساعت ۸ صبح گزارش محلی را می‌سازد. زمان‌بندی Vercel مستقل اجرا می‌شود و پس از انتشار، برای به‌روزرسانی داشبورد به روشن بودن این سیستم نیاز ندارد.
